# AI Meeting Analyzer

This application analyzes meeting recordings and transcripts to provide insights into meeting dynamics, sentiment, topic drift, and speaker contributions.

## Components

- **Dashboard**: React-based frontend and Node.js backend
- **Analysis**: Python Flask API for data analysis and visualization
- **Chatbot**: Interactive assistant for meeting insights
- **Meeting Bot**: Automated meeting recording and transcription
- **Transcripts**: Transcript processing and management

## Getting Started

For detailed setup instructions, see the following documentation:

## Running the Application

To run the complete application with all components:

1. Start the Flask API for data analysis
2. Start the Node.js backend 
3. Start the React frontend

Refer to the [Flask Integration Guide](dashboard/FLASK_INTEGRATION.md) for detailed instructions.
